# Day 18 — Facts, Variables, Affinity, Log Archiving

## 🔹 Ansible — Use Ansible Facts


--- 
- name: Show system facts for Pathnex
  hosts: all

  tasks:
    - name: Print OS info
      debug: 
        var: ansible_facts['os-family']

    - name: Print IP address
      debug:
        var: ansible_facts['default_ipv4']['address']

##
--- — Marks the beginning of the YAML document.
name — Describes the playbook or task.
hosts: all — Runs against all hosts in the inventory.
tasks — Defines the actions to execute.
debug — Displays information in the Ansible output.
ansible_facts['os_family'] — Shows the OS family, such as Debian or RedHat.
ansible_facts['default_ipv4']['address'] — Shows the default IPv4 address discovered on the host.

## Shell Script — Archive Log Files

#!/bin/bash

tar -czf /backup/pathnex-logs-$(date +%F).tar.gz /var/log/
echo "log archived"

              
$() — Executes the command inside and substitutes its output.
date — Displays the current date and time.
+%F — Formats the date as YYYY-MM-DD.


## Jenkins Pipeline — Rollback on Failure

**simulate rollback if deployment fails**.

pipeline {
  agent any 

  environment {
    INSTITUTE_NAME = "Pathnex"
  }

  stages {
    stage ('Deploy') {
      steps{
        script {
          try {
            sh 'echo "Deploy $INSTITUTE_NAME application..." '
            sh 'exit 1' // simulate failure
                    } catch (Exception e) {
                        echo "Deployment failed. Rolling back $INSTITUTE_NAME application..."
          }
        }
      }
    }
  }
}

## GitLab CI — Rollback Simulation

stages:
  - deploy

variables:
  INSTITUTE_NAME: "Pathnex"

deploy:
  stage: deploy
  image: alpine:latest
  script:
    - echo "Deploying $INSTITUTE_NAME application..."
    - exit 1
  after_script:
    - echo "Deployment failed. Rolling back $INSTITUTE_NAME application..."
