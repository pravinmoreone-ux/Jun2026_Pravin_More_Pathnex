## 2️⃣ Ansible — Install Nginx & Deploy HTML File


---
- name:  Install Nginx & Deploy HTML File
  hosts: all
  become: yes

  tasks:
    - name: install nginx
      yum:
        name: nginx
        state: present

    - name: start and enable nginx
      service:
        name: nginx
        state: started
        enables: yes

    - name: Deploy HTML File
      copy: 
        content: |
          <!Document html>
          <html>
          <head>
            <title> My Ansible Server </title>
          </head>
          <body>
              <h1> Hello From Ansible </h1>
              <p> Nginx was installed </p>
          </body>
          </html>
        dest: /usr/share/nginx/html/indx.html
        owner: root
        group: root
        mode: '0644'

# Scheduled Pipelines

## 🔹 Jenkins Pipeline — Scheduled Build
You will learn how to **schedule a Jenkins pipeline using cron**.

pipeline {
    agent any
    environment {
        INSTITUTE_NAME = "Pathnex"
    }
    triggers {
        cron('H 2 * * *') // every day at 2 AM
    }
    stages {
        stage('Checkout') {
            steps {
                git url: 'https://github.com/Pathnex/sample-java-app.git'
            }
        }
        stage('Build') {
            steps {
                sh 'mvn clean package'
            }
        }
    }
}
