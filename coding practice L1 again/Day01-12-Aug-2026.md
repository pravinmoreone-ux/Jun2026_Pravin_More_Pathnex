# Git Integration
## 🔹 Jenkins Pipeline — Checkout Git


You will learn how to **checkout a Git repository** and list files

pipeline {
    agent any

    stages {
        stage('Checkout') {
            steps {
                git branch: 'main' , url: 'https://github.com/prvin/sample-java-app.git'
            }
        }

        stage('List File') {
             steps {
                sh 'ls -la'
             }   
        }
    }
}
