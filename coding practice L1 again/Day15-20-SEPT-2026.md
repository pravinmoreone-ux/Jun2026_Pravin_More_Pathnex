 # Day 15 — Java, S3 Bucket, CronJob, File Reader

## 🔹 Ansible — Install Java & Set JAVA_HOME

---
- name: Install Java and set java hokme
  host: all
  become: yes

  tasks:
    - name: Install java on server
      yum:
        name: java-11-openjdk
        state: present

    - name: Set Java_Home
      lineinfile:
        path: /etc/profile
        line: 'export JAVA_HOME=/usr/lib/jvm/java-11-openjdk'
