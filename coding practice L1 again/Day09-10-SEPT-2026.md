## 🔹 GitLab CI — Artifacts
You will learn how to **store artifacts in GitLab CI**.

stages:
  - build

build:
  stage: build
  image: maven:3.8.1-jdk-17
  script:
    - git clone https://github.com/Pathnex/sample-java-app.git
    - cd sample-java-app
    - mvn clean package
  artifacts:
    paths:
      - target/*.jar
    expire_in: 1 week


### Git action 


name: Build Java Appplication

on:
  push:
    branches:
      - main


jobs:
  build:
    runs-on: ubuntu-latest

steps:
  
  - name: Checkout Repository
    uses: actions/checkout@v4

  - name: set up Java 17
    uses: actions/setup-java@v4
    with:
      distribution: temurin
      java-version: '17'

  - name: Clone sample Java application
    run: |
          git clone https://github.com/Pathnex/sample-java-app.git

  - name: Build with Maven
    run: |
          cd sample-java-app
          mvn clean package

  - name: Upload JAR artifact
    uses: actions/upload-artifact@v4
    with:
      name: java-application
      path: sample-java-app/target/*.jar
      retention-days: 7






      ###

      Keyword	Meaning
on	When should workflow run?
jobs	What work should be performed?
runs-on	Which machine runs the job?
steps	Individual actions/commands
uses	Use a pre-built GitHub Action
run	Run a shell command
with	Give configuration to an action
