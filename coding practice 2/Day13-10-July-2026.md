| Feature       | `at`                         | `job` (Linux/Kubernetes)        | `cron`                       | `CronJob`                       |
| ------------- | ---------------------------- | ------------------------------- | ---------------------------- | ------------------------------- |
| Purpose       | Run something **once later** | Run a **task once**             | Run something **repeatedly** | Run Kubernetes tasks repeatedly |
| Environment   | Linux/Unix                   | Linux or Kubernetes             | Linux/Unix                   | Kubernetes                      |
| Frequency     | One time                     | One time                        | Repeated schedule            | Repeated schedule               |
| Managed by    | `atd` daemon                 | Shell/Kubernetes Job controller | `crond` daemon               | Kubernetes CronJob controller   |
| Runs as       | Linux process                | Process or Pod                  | Linux process                | Kubernetes Job → Pod            |
| Configuration | `at` command                 | Command/YAML                    | crontab                      | YAML manifest                   |
