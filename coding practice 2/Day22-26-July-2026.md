🔹 Ansible — Deploy Nginx Across Multiple Kubernetes Clusters


- name: Deploy nginx across multiple k8s cluster
  hosts: all
  become: yes
  tasks: 
    - name: Config k8s for cluster 1
      command: kubectl --context=us-east config use-context us-east-cluster

    - name: DEploy nginx on cluster 1
      command: kubectl apply -f kubernetes/deployment.yaml

    - name: Config k8s for cluster 2
      command: kubectl --context=us-west config use-context us-west-cluster

    - name: DEploy nginx on cluster 2
      command: kubectl apply -f kubernetes/deployment.yaml

🔹 Kubernetes — Federated Deployment with Multiple Clusters


apiVersion: apps/v1
kind: Deployment
metadata: 
  name: pravin-deployment
spec:
  replicas: 3
  selector:
    matchLabels:
      app: pravin-app
  template:
    metadata:
      labels:
        pravin-app
    spec:
      containers:
        - name: nginx
          image: nginx
          ports:
            - containerPort: 80

Q: Kubernetes Federation is deprecated. What is used now?

"The original Federation API (federation.k8s.io/v1beta1) has been deprecated. Nowadays, most organisations use Argo CD, especially ApplicationSet, to deploy the same application across multiple Kubernetes clusters using GitOps. In OpenShift environments, Open Cluster Management (OCM) is also widely used, while KubeFed v2 is available for federation-specific use cases but is less commonly adopted than Argo CD."



🔹 Jenkinsfile — Multi-Cluster Deployment Strategy
pipeline {
    agent any
    stages {
        stage('Deploy to Cluster 1') {
            steps {
                script {
                    sh 'kubectl --context=us-east-cluster apply -f kubernetes/deployment.yaml'
                }
            }
        }
        stage('Deploy to Cluster 2') {
            steps {
                script {
                    sh 'kubectl --context=us-west-cluster apply -f kubernetes/deployment.yaml'
                }
            }
        }
    }
}
