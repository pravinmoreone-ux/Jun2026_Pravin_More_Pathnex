Day 21 — Disaster Recovery and Backup Strategies
🔹 Ansible — Backup and Restore Files


- name: BAckup and Restore file
  host: all
  become: yes
  tasks:
    - name: Create backup of /etc directory 
      command: tar -cxvf /tmp/etc-backup.tar.gz /etc
    - name: Copy backup to remote server
      copy:
        src: /tmp/etc-backup.tar.gz
        dest: /tmp/etc-backup.tar.gz
    - name: Restore backup from remote server
      command: tar -xzvf /tmp/etc-backup.tar.gz -C /
  

  | Option | Meaning                 |
| ------ | ----------------------- |
| `-x`   | Extract                 |
| `-z`   | Uncompress gzip         |
| `-v`   | Verbose                 |
| `-f`   | Archive file            |
| `-C /` | Restore into root (`/`) |

🔹 Kubernetes — Disaster Recovery with Persistent Volumes


apiVersion: apps/v1
kind: StatefulSet
metadata:
  name: pravin-statefulset
spec:
  serviceName: "pravin"
  replicas: 3
  selector:
    matchLabels:
      app: pravin
  template:
    metadata:
      labels:
        app: pravin
    spec:
      containers:
        - name: nginx
          image: nginx
          volumeMounts: 
            - name: web-content
              mountPath: /usr/share/nginx/html
    
    volumeClaimTemplate:
      - metadata: 
          name: web-content
        spec:
          accessMode:
            - ReadWriteOnce
          resources:
            requests:
              storage: 5Gi

🔹 Jenkinsfile — Backup Strategy for Jenkins Workspace

pipeline {
    agent any
    stages {
        stage ('Backup'){
            steps {
                echo 'Backing up Jenkins workspaces .... '
                sh 'tar -cxvf /tmp/jenkins-backup.tar.gz ${WORKSPACE}'
            }
        }

        stage ('Restore'){
            steps {
                echo 'Backing up Jenkins workspaces .... '
                sh 'tar -xzvf /tmp/jenkins-backup.tar.gz -C ${WORKSPACE}'
            }
        }

    }
}
