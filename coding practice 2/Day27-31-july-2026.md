🔹 Jenkinsfile — Lambda Function Deployment Pipeline

pipeline {
    agent any
    stages{
        stage('Build'){
            steps {
                    echo 'Build lambda unction package ...'
                    sh 'zip -r lambda.zip /lambda'
            }
        }

        stage('Deploy to Lambda') {
            steps {
                script {
                    sh 'aws lambda update-function-code --function-name pravin-lambda --zip-file fileb://lambda.zip'
                }
            }
        }

    }

| Option            | Explanation                                                                                                               |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `docker run`      | Creates and starts a new container from an image.                                                                         |
| `-d`              | Runs the container in **detached mode** (in the background).                                                              |
| `--memory="512m"` | Limits the container to a maximum of **512 MB RAM**. If it exceeds this limit, it may be **OOMKilled (Out of Memory)**.   |
| `--cpus="1.0"`    | Limits the container to using **1 CPU core** (100% of one CPU).                                                           |
| `nginx`           | Uses the **nginx** image to create the container. If the image is not available locally, Docker pulls it from Docker Hub. |
