resource "aws_iam_role" "ec2_role" {
    name = "pravin-ec2_role"
    assume_role_policy = jsonencode({
        Version = "2012-10-17"
        Statement = [
            {
                Action = "sts:AssumeRole"
                Effect = "Allow"
                Principal = {
                    Service = "ec2.amazonaws.com"
                }
            },
        ]
    })
}


resource "aws_instance" "pravin_ec2" {

        Name = "Pravin_ec2"
    }
}

Which type should you use?
Application passwords, API keys, database credentials → Opaque
HTTPS certificates → kubernetes.io/tls
Private container registry credentials → kubernetes.io/dockerconfigjson
Username/password authentication → kubernetes.io/basic-auth
SSH private keys → kubernetes.io/ssh-auth
Service account tokens → kubernetes.io/service-account-token

| Command                         | Purpose                             |
| ------------------------------- | ----------------------------------- |
| `tar -cf archive.tar dir/`      | Create an uncompressed tar archive  |
| `tar -czf archive.tar.gz dir/`  | Create a gzip-compressed archive    |
| `tar -cjf archive.tar.bz2 dir/` | Create a bzip2-compressed archive   |
| `tar -cJf archive.tar.xz dir/`  | Create an xz-compressed archive     |
| `tar -xf archive.tar`           | Extract an uncompressed tar archive |
| `tar -xzf archive.tar.gz`       | Extract a gzip-compressed archive   |
| `tar -tvf archive.tar`          | List the contents of an archive     |

Docker Java Application
Hello.java

class Hello {
    public static void main(String args[]){
        System.out.println("Hello World!")
    }
}   

>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>

# Docker File

FROM openjdk:17
WORKDIR /opt/pravin/java-app
COPY Hello.java /opt/pravin/java-app/
RUN javac /opt/pravin/java-app/Hello.java
CMD ["java", "-cp" , "/opt/pravin/java-app", "Hello"]

>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>

Breaking it down
java → Starts the Java Virtual Machine (JVM)
-cp → Sets the classpath
/opt/pathnex/java-app → Directory where Hello.class is located
Hello → Name of the class containing the main() method (without .class)
