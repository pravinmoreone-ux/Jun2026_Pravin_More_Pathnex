iew Tip

If asked:

"Do companies still use Launch Configurations?"

A good answer is:

No. Launch Configurations are a legacy feature. In modern AWS environments, Auto Scaling Groups are created using Launch Templates because they support newer EC2 features such as multiple instance types, newer AMIs, versioning, IMDSv2, and advanced networking options. Most production environments have migrated to Launch Templates.

### Create a Target Group

resource "aws_lb_target_group" "pravin_tg" {
    name            = "pravin_tg"
    port            = 80
    protocol        = "HTTP"
    vpc_id          = aws_vpc.main.ip

    health_check {
        path = "/"
        port = "traffic-port"
    }

}

### Register EC2 with Target Group

resource "aws_lb_target_group_attachment" "ec2_attach" {
    target_grp_arn              = aws_lb_target_group.pravin_tg.arn
    target_id                   = aws_instance.pravin_ec2.id
    port                        = 80
}

### Create Listener
### "Whenever traffic comes on port 80, forward it to this Target Group.

resource "aws_lb_listener" "http" {
    load_balancer_arn = aws_lb.pravin_lb.arn
    port              = 80
    protocol          = "HTTP"

    default_action {
    type             = "forward"
    target_group_arn = aws_lb_target_group.pravin_tg.arn
  }

}


| Terraform Resource               | Purpose                         |
| -------------------------------- | ------------------------------- |
| `aws_lb`                         | Creates the Load Balancer       |
| `aws_lb_listener`                | Opens port and forwards traffic |
| `aws_lb_target_group`            | Defines backend servers         |
| `aws_lb_target_group_attachment` | Registers EC2 with Target Group |
